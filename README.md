# 个人饮食管理项目（SmartNutrient）

SmartNutrient 是一个面向个人日常使用的离线 Android 饮食记录应用。它把“吃了什么、吃了多少、怎么做”转换成可回看的营养数据，帮助使用者持续记录三餐、独立食材、水果、饮品、调料和补剂，并通过日历、周总结与智能推荐了解每天的饮食结构。

> 当前版本：**0.5.1**（versionCode 24）  
> 最低系统：Android 8.0（API 26）  
> 应用包名：`com.smartnutrient.app`

## 功能概览

### 饮食记录

- 按早餐、午餐、晚餐和加餐记录食物。
- 输入实际克数或毫升数，自动换算本份营养。
- 支持“不加油、低油、中油、高油”和“不加盐、低盐、中盐、高盐”。
- 油盐量跟随食物基准份量同比缩放，不再固定追加整份油盐；每 100g 食物与“每份”食品分别使用正确的换算基准。
- 支持成品菜、独立食材、调料、水果、饮品、补剂六类标签。
- 食物卡片显示类型、基础口径、做法、数据质量和常用分量。
- 支持关键词、多关键词、拼音和首字母搜索，并优先展示收藏与最近食物。
- 支持自定义食物、常用组合、一餐复制和“复制昨日”。

### 营养统计

首页集中显示当天摄入与推荐区间，覆盖：

- 热量
- 蛋白质
- 脂肪
- 饱和脂肪
- 碳水化合物
- 膳食纤维
- 总糖
- 钠
- 钾
- 胆固醇

添加糖仅在数据可靠时显示；缺少可信配方数据时整项隐藏，不按 0 处理。食物详情、添加预览和日历汇总展示本份完整营养，不混用每日推荐区间。

### 食物数据库

- 当前普通食物目录约 1,416 条：主食、菜品、水果、基础食物、独立食材、饮品和补剂。
- 另有 40 种可独立记录和自由搭配的调料。
- 区分生重、熟重、干重、可食部、每 100g、每 100ml 和每份口径。
- 区分米饭与生大米、面条与生面条、全麦意面与普通意面等不同状态。
- 方便面支持“仅面饼”和“含调料包整套”，避免营养与油盐重复计算。
- 菜谱中出现的食材可独立检索和称重，例如黄豆、鹰嘴豆、鸡胸肉、黄瓜等。
- 每条食物记录包含来源、置信度和适用口径；无法可靠核实的数据明确标为估算。

### 日历与复盘

- 日历按日期回看饮食、饮水、餐次和完整营养素。
- 当日详情展示运动消耗、步数、步行净消耗和推荐中心热量。
- 近 7 天总结展示实际累计、推荐累计和带单位的偏差。
- 支持合并导入或覆盖导入 SmartNutrient JSON 备份。
- 每日自动备份最多保留 7 份，手动恢复前额外保留快照。
- 备份文件可通过系统分享面板发送到微信、网盘或邮件。

### 身体目标与智能推荐

- 根据年龄、性别、身高、体重、身材类型和活动信息估算静息消耗。
- 可填写额外运动热量和当天步数，计算推荐能量。
- 支持减脂、维持和增重目标。
- 支持每日身体测量与 7/30/90 天趋势；同一天只保留最后一条记录。
- 自适应目标默认关闭，开启后才根据历史体重和饮食记录修正目标。
- 早餐与午餐均记录后启用智能推荐；只推荐食材或水果，不推荐成品菜。
- 推荐综合考虑蛋白质、纤维、钾、碳水缺口，以及脂肪、钠、糖和胆固醇负担。

## 数据与隐私

- 应用完全离线运行，不申请网络、相机、麦克风或定位权限。
- 饮食记录、身体档案、饮水、模板和备份均保存在本机。
- 不包含账号系统、广告 SDK 或第三方行为分析 SDK。
- 食物营养值来自公开食物成分资料、包装标签和标准配方估算，属于记录与教育用途，不替代医生或注册营养师建议。
- 高钠、高能量或干制海产数据可能看起来偏高，但它们可能符合真实克重与加工口径，不应为了“好看”机械调低。

## 项目结构

```text
app/
├── src/main/java/com/smartnutrient/app/   # 界面、营养计算、食物目录与本地存储
├── src/main/res/                          # 应用主题、图标与资源
├── src/test/java/com/smartnutrient/app/    # 营养、搜索、备份、日历与推荐测试
└── build.gradle.kts                       # Android 构建配置
tools/                                     # 食物数据审计与缓存工具
```

核心计算入口位于 `NutritionEngine.kt`。所有记录营养统一使用 `recordSnapshot`，确保首页、添加预览、日历、近 7 天总结和智能推荐采用同一份量与油盐口径。

## 本地构建

环境要求：

- JDK 17
- Android SDK Platform 35
- Android Build Tools 35
- Gradle 8.11.1

在项目根目录创建未提交的 `local.properties`：

```properties
sdk.dir=/path/to/Android/Sdk
```

运行全量测试并构建 Debug APK：

```bash
gradle clean :app:testDebugUnitTest :app:assembleDebug --console=plain
```

构建产物位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```
